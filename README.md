# VoiceReach OS (ویس‌ریچ) — سیستم‌عامل ارتباطات صوتی کسب‌وکارهای ایران

**VoiceReach OS** یک پلتفرم یکپارچه، بومی‌سازی‌شده و تک‌سازمانی با پشتیبانی از چندشعبه‌ای (**Single-Tenant + Multi-Branch**) برای مدیریت مرکز تماس، منشی تلفنی هوشمند (AI IVR)، کمپین‌های تماس خروجی، CRM (پرونده ۳۶۰ درجه مشتری)، نوبت‌دهی تقویم جلالی، صدور فاکتور با چاپگر حرارتی و اتوماسیون پیامکی است.

---

## قابلیت‌های کلیدی

1. **میز کار منشی و مرکز تماس (Screen Pop):** نمایش آنی پرونده مشتری با شروع زنگ، میانبرهای صفحه کلید (`A`, `R`, `E`, `H`, `M`, `C`)، ثبت یادداشت و نتیجه مکالمه، و پخش امن مکالمات ضبط‌شده با لینک امضاشده (`temporarySignedRoute`).
2. **منشی هوشمند فارسی (Smart AI Receptionist & Visual Flow Builder):** طراح بصری جریان تماس (IVR)، تشخیص نیت گفتار فارسی (رزرو نوبت، استعلام صورت‌حساب، ثبت تیکت، انتقال به اپراتور، لغو تماس)، تغییر حالت پاسخگویی (`human_only`, `ai_only`, `hybrid`) و شبیه‌ساز زنده مکالمه.
3. **موتور کمپین صوتی خروجی و لیست سیاه (DNC):** اجرای کمپین‌های انبوه با بررسی اجباری لیست عدم تماس (`DNCChecker`) قبل از ارسال به صف، رعایت ساعات مجاز تماس به وقت تهران (`Asia/Tehran`) و زمان‌بندی تلاش مجدد.
4. **پرونده ۳۶۰ درجه مشتری (CRM):** مدیریت مخاطبان، برچسب‌ها، یادداشت‌ها، فایل‌های پیوست، ادغام مخاطبان تکراری و تایم‌لاین کامل تعاملات.
5. **موتور نوبت‌دهی و تقویم جلالی:** محاسبه هوشمند زمان‌های خالی بر اساس شیفت کاری پرسنل، استراحت‌ها، مرخصی‌ها، تعطیلات رسمی و فاصله بین نوبت‌ها (`buffer_minutes`) همراه با یادآور خودکار پیامکی.
6. **امور مالی، فاکتور، دفتر کل و چاپگر حرارتی (`dqnamo`):** محاسبه مالیات بر ارزش افزوده (۹٪)، تخفیف، ثبت پرداخت (نقدی، کارتخوان، کیف پول، چک، درگاه زرین‌پال/آیدی‌پی)، ثبت خودکار سند بدهکار/بستانکار و انیمیشن ۷ مرحله‌ای چاپ فیش حرارتی.
7. **اتوماسیون پیامک با Failover خودکار:** اتصال به کاوه‌نگار و قاصدک با سوییچ خودکار در صورت بروز خطا و موتور قالب‌های متغیرمحور.
8. **گزارش‌های مدیریتی و آنالیتیکس:** نمودارهای تحلیلی تماس، درآمد، کمپین و عملکرد اپراتورها با خروجی CSV.
9. **اکوسیستم توسعه‌دهندگان، وب‌هوک‌ها و ویزارد نصب:** مدیریت کلیدهای API (`Sanctum`)، وب‌هوک‌های خروجی امضاشده با `HMAC-SHA256`، لاگ ممیزی (`Audit Trail`)، ویزارد نصب تحت وب (`/setup`) و دستورات CLI (`voicereachos:install`, `voicereachos:health`, `voicereachos:backup`).

## پشته فناوری (Tech Stack)

- **بک‌اند:** Laravel 13, PHP 8.3, SQLite / MySQL 8, Redis, Laravel Horizon, Laravel Reverb, Laravel Sanctum, Spatie Permission
- **فرانت‌اند:** React 19, TypeScript, Vite 8, Tailwind CSS v4, TanStack Query v5, Zustand, React Router v7, Recharts, Framer Motion
- **فونت و رابط کاربری:** فونت کاملاً محلی `IranYekan` (بدون وابستگی به CDN)، کامپوننت‌های پایه VibeFarsi، کامپوننت‌های تعاملی Devigner UI و چاپگر حرارتی dqnamo
